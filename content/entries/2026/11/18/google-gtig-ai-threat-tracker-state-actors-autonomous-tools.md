Google's Threat Intelligence Group and Mandiant said on November 16 that Chinese government-backed groups appear to be developing their own version of the ARTEX framework for likely use in espionage, and that state-backed and criminal actors are using AI tools for reconnaissance, exploit development and sorting stolen data. The same report describes what Google calls the first intrusion run end to end by AI, an automated patch-diffing and exploitation pipeline whose code contains Russian-language comments and whose victims included French media, entertainment and education websites. Google did not name a group or state behind that operation.
